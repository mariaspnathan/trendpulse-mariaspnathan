**TrendPulse - Mini Project**

A data pipeline project where you fetch live trending data, clean it, analyse it, and visualise it — built across 4 Python scripts.

Source Codes: 
  1. task1_data_collection.py
  2. task2_data_processing.py
  3. task3_analysis.py
  4. task4_visualization.py

Output Files: 
  1. raw_trends.json
  2. clean_trends.json
  3. analytics_summary.json
  4. FinalOutput.png
